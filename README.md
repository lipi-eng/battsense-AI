# BattSense AI — Lithium-Ion Battery Temperature Prediction

**ME Third-Year Assignment — 15 Marks**

Predicts measured battery temperature (°C) from electrical operating parameters
using the NASA Li-ion Battery Aging Dataset. Two regression models are compared:
Linear Regression (baseline) and XGBoost (main model). A Streamlit web app
provides an interactive interface for live predictions and result inspection.

## Running the project

### Step 1 — Train models

```bash
python main.py
```

This trains Linear Regression and XGBoost on 80 % of discharge cycles,
evaluates both on the held-out 20 %, saves all metrics and plots to `results/`,
and saves the trained models to `models/`.

### Step 2 — Launch the web app

```bash
streamlit run app.py
```

Open your browser at **http://localhost:8501** (or the URL printed in the terminal).

## Dataset

**NASA Li-ion Battery Aging Dataset** — PCoE Research Center
Batteries B0005, B0006, B0007, B0018 — discharge cycles only.
185,721 rows, 636 cycles. Ambient temperature is constant at 24 °C (excluded from features).

---

## Key design decisions

**Cycle-based split.** Rows within a discharge cycle are time-correlated.
Splitting by cycle (not by row) prevents the model from memorising a cycle's
trajectory instead of generalising to unseen cycles.

**Ambient temperature excluded.** The NASA lab held the chamber at exactly 24 °C
throughout; the column is constant and carries no predictive information.

**Preprocessing on training data only.** `StandardScaler` is fitted on the
training set only and applied to the test set, preventing leakage.

**Models not retrained on app start.** `app.py` loads saved model files from
`models/` using `@st.cache_resource`, so startup is instant.

---

## Limitations

- Ambient temperature is fixed at 24 °C — the model cannot generalise to
  different environmental conditions.
- Data comes from individual 18650 cells, not a full EV battery pack.
- Predictions outside the training range (voltage 1.74 – 4.23 V,
  current −2.03 – 0.01 A, time 0 – 3690 s) are unreliable.
- The model estimates temperature at the current operating state; it does not
  predict future overheating or control any safety system.
